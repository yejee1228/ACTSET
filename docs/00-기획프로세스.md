# ACTSET 기획 프로세스 설계 (Stage 0)

> **서비스명: ACTSET** (반달컴퍼니 공연 특화 AI 홍보물 제작 플랫폼)

## 목적

사업계획서(전략 수준의 Why/What)를 실제 개발 가능한 서비스 기획서(How) 수준으로 구체화하기 위한 단계별 로드맵이다. 각 단계는 이전 단계의 산출물을 입력으로 삼아 다음 단계로 진행하며, 최종적으로 Claude Code가 개발 시 참조할 수 있는 기획 문서 세트를 완성하는 것을 목표로 한다.

## 문서 관리 원칙

- 이 레포(`bandal-promo-platform/`)의 `docs/` 폴더에 단계별 기획 문서를 번호순 markdown 파일로 축적한다.
- 사업계획서(전략) ↔ 기획 문서(실행) ↔ 코드(구현) 순으로 컨텍스트가 이어지도록 관리한다.
- 각 문서는 확정본이 아니라 다음 단계로 넘어가기 전 확인·수정하는 작업본이다.

## 진행 원칙

1. 매 단계 초안을 먼저 제시하고, 확인·수정을 거쳐 확정한 뒤 다음 단계로 진행한다.
2. 이전 단계 문서는 다음 단계의 입력으로 사용한다. 예를 들어 데이터모델이 확정되어야 화면기획에서 어떤 필드가 어느 화면에 노출되는지 정할 수 있다.
3. 뒷 단계에서 발견한 문제로 앞 단계를 수정해야 하면 해당 문서로 돌아가 갱신한다. 순서는 있지만 왕복은 허용한다.
4. 이미 존재하는 프로토타입은 각 단계에서 "이미 있는 것"과 "새로 설계할 것"을 구분하는 기준점으로 사용한다.

## 기획 범위에서 제외

- 사업계획서에서 이미 제외한 항목: 공연 정산, 인력관리, 대관관리, 공연장 ERP, 티켓 판매, 좌석·발권 관리, 커뮤니티, 광고집행, 범용 PPT 제작, 범용 디자인 에디터
- 후속 확장 후보(공연 출시 준비 대시보드, 채널별 등록자료 패키지)는 이번 기획 로드맵에 포함하지 않고 별도 백로그로만 기록한다.

# 개발 티켓 (Stage 13)

> Stage 7의 에픽을 Claude Code 작업 단위로 분해한다. 티켓 하나는 **한 세션에 끝낼 수 있는 크기**를 기준으로 잡았다.

## 티켓 읽는 법

- `[선행]` 먼저 끝나야 하는 티켓
- `[완료기준]` 무엇을 확인하면 끝난 것으로 보는가
- 티켓 번호는 에픽-순번 형식이며 번호가 실행 순서를 뜻하지는 않는다

**0-5~0-8은 법무 항목이라 개발과 병행할 수 있으나, 가입 화면(1-4)이 열리기 전에는 끝나야 한다.** 동의 없이 개인정보를 수집하면 그 시점부터 위법이다.

**[완료 시점]** 정보 입력 → 시안 생성 → 선택 → 프로젝트 생성까지 시연 가능해진다. 협약기간 내 목표의 중심이다.

## 착수 순서 제안

두 사람이 나눠 진행하는 것을 전제로 한다.

1. **1주차** — 1-1~1-4(기반), 병행하여 0-1·0-2·0-3 진행
2. **2주차** — 1-5~1-8(입력 화면), 1-9~1-10(워커·렌더링)
3. **3주차** — 1-11~1-14(시안 생성·확정) → **여기서 첫 시연이 가능해진다**
4. **4주차** — 3-3 아웃페인팅 실험을 먼저 하고, 결과에 따라 E3 방향 확정
5. 이후 E2(학습)와 E3(규격)를 병행

3-3 실험을 4주차에 앞당긴 이유는, 실패했을 때 설계를 되돌리는 비용이 뒤로 갈수록 커지기 때문이다.

# 사용자 플로우 / 정보구조 (Stage 3)

## 목적

기존에 확정된 유저 플로우 8단계를 Stage 2의 Role Schema, Stage 1의 MVP 범위 기준으로 화면 단위까지 구체화한다. 이 문서가 확정되어야 Stage 4(화면별 상세기획)에서 각 화면의 UI 요소를 설계할 수 있다.

## 전체 사이트맵

```
소개 페이지 (비로그인 첫 화면 — 서비스 소개·가입 유도)
 └─ 로그인/회원가입
      └─ 홈 대시보드 (로그인 후 첫 화면 — 내 프로젝트 목록)
           ├─ [새 프로젝트 만들기] → 신규 생성 플로우 (①~④ → ④-1 다음 행동 선택 → ⑤~⑥)
           ├─ [기존 프로젝트 복제] → PerformanceInfo·DesignAssets 복사한 새 프로젝트 생성 → 프로젝트 대시보드(⑦)로 이동
           └─ [기존 프로젝트 클릭] → 프로젝트 대시보드(⑦) 진입
                                        ├─ 정보 수정 화면 (6-1, ①+② 통합 폼 재사용)
                                        │    → 저장 시 포스터는 자동 반영, 나머지는 "최신 반영" 버튼으로 일괄 반영
                                        ├─ 결과물 개별 삭제(소프트 삭제)
                                        └─ 추가 제작(MVP 비활성) / 인쇄 진입(⑧까지 제공, 결제만 비활성)
```

**용어 구분(혼동 방지)**
- **홈 대시보드**: 로그인 직후 도착하는 계정 단위 화면. 내가 만든 프로젝트 목록과 "새 프로젝트 만들기" 버튼이 있다.
- **프로젝트 대시보드(⑦)**: 특정 공연 하나의 생성물을 관리하는 화면.

신규 생성 플로우는 홈 대시보드의 "새 프로젝트 만들기" 버튼에서 시작하며, 소개 페이지나 로그인 화면이 직접 진입점이 되지 않는다.

MVP에서도 재방문 시나리오(과거 공연 프로젝트 확인 → 공연정보 변경 → 새 제작물 생성, 사업계획서 S-5)를 지원해야 하므로, 홈 대시보드가 모든 작업의 시작점이다.

## 신규 생성 플로우 (① ~ ④-1, 이후 ⑤~⑦은 필요할 때 진입)

### ① 공연 정보 입력 (필수 최소정보)

- **목적**: 시안 생성에 필요한 최소 정보만 빠르게 받는다.
- **입력 필드**: genre(장르 7종 중 선택, 미정 불가), main_title(공연명, 미정 불가), venue(장소 — 입력 또는 "장소 미정" 선택), sessions 중 대표 날짜 1건(날짜 — 입력 또는 "날짜 미정" 선택, 시간 제외)
- **액션**: 다음(추가정보 입력으로) — 4항목을 모두 채워야(또는 미정 선택) 진행 가능. 건너뛰기는 없음
- **처리**: 이 화면에 진입하는 순간 Project 레코드를 `status='draft'`로 생성한다(Stage 2 참고). 이후 ①·②의 입력값과 ③의 후보·선택 로그가 모두 이 draft 프로젝트에 귀속된다
- **비고**: 필수 4항목은 반드시 입력해야 하며, 그중 날짜·장소는 실제 값 대신 "미정"을 선택할 수 있다(Stage 2 sessions/venue의 `is_undetermined` 참고). 장르·공연명은 미정 불가

### ② 추가정보 입력 (선택, 스킵 가능)

Role Schema의 선택 필드를 아래 그룹으로 나눠 입력받는다. 전체를 채우지 않아도 다음 단계로 진행 가능하다.

| 그룹 | 필드 |
|---|---|
| 일정 상세 | sessions 추가 회차, 각 회차 시간, running_time(러닝타임) |
| 부가 정보 | subtitle, age |
| 출연진 | cast[] |
| 가격 | price_items[] (좌석등급/시점별가격/할인) |
| 주최 정보 | organizer_group (주최/주관/후원 각각 입력) |
| 안내 | inquiry, ticket_channels[] |
| 소개 | introduction, synopsis, program[] |
| 이미지·색상 | performance_photos[], reference_images[], logo, brand_colors[] |
| 문구·이미지 방향 | mandatory_notices(포스터에 꼭 들어가야 하는 문구), image_direction_note(원하는 이미지 방향 자유서술 — 필수정보 중 일부를 이 시안에 넣지 말아달라는 지시도 가능) |

### ③ 시안 선택 화면

- **목적**: ①·②의 정보와 장르 배치 기준을 바탕으로 AI가 생성한 기본 시안 후보를 제시하고 사용자가 방향을 좁히도록 한다.
- **표시**: 시안 후보 N개(카드형)
- **액션**: 선택 / 다른 방향 보기(새로운 스타일 후보) / 재생성(같은 방향 유지, 다시 생성) / 이 방향으로 더 보기(선택한 후보와 유사한 후보 추가 생성)
- **출력**: 사용자가 최종 선택한 시안 1건
- **데이터 수집(핵심)**: 화면에서 발생하는 모든 액션(선택/다른방향보기/재생성/이방향으로더보기)을 SelectionEvent로 기록한다(Stage 2 참고). 액션 발생 시점에 함께 제시된 후보 전체(shown_candidates)까지 반드시 저장해야 "무엇과 비교해서 골랐는지"가 남아 추천엔진 고도화에 쓸 수 있다

### ④ 시안 결정 및 프로젝트 확정

- **목적**: ③에서 확정한 시안을 DesignAssets로 고정하고 draft 프로젝트를 정식 프로젝트로 확정한다(프로젝트를 새로 만드는 단계가 아니라 `draft → active`로 전환하는 단계다).
- **처리**: Project.status를 `active`로 전환(confirmed_at 기록), DesignAssets(key_visual_image, palette, representative_photo, title_typography_style, selected_variant_id) 확정, 선택된 시안후보 레코드를 `category='포스터'`, `auto_sync_text=true`로 전환
- **다음**: ④-1로 이동

### ④-1 프로젝트 생성 완료 — 다음 행동 선택

- **목적**: 시안 확정 직후 바로 규격 변환으로 이어가지 않을 수 있다는 점을 반영한 선택 화면. 프로젝트가 만들어졌음을 알리고 다음 행동을 사용자가 고르게 한다.
- **표시**: "프로젝트가 생성되었습니다" 안내 + 확정된 포스터 미리보기
- **액션**: 대시보드로 이동(⑦) / 지금 바로 홍보물 만들기(⑤로 이동)
- **비고**: 이 화면 추가로 신규 생성 플로우는 ①~④-1까지가 "프로젝트 생성" 구간이고, ⑤~⑥은 필요할 때 언제든 다시 들어올 수 있는 별도 구간이 된다

### ⑤ 홍보물 생성 페이지 (규격 복수선택)

- **목적**: 기본 규격 목록에서 필요한 것을 복수 선택한다.
- **표시**: 변환 대상 **12종**(NOL티켓·티켓링크·플레이티켓/SNS 1:1·4:5/스토리/홈페이지 썸네일·배너/DID/공연장모니터/현수막/X배너) + **원본 포스터 다시 만들기** 1종을 함께 노출한다
- **포스터의 위치**: 포스터는 다른 규격과 동렬의 변환 대상이 아니라 프로젝트의 **대표 이미지(원본)**이므로, 목록에서도 별도 영역에 "원본 다시 만들기"로 구분해 표시한다. 선택해서 새 안을 확정하면 새 결과물이 추가되는 것이 아니라 **기존 포스터가 교체**된다(Stage 2 중복 방지 규칙 참고)
- **포스터 재생성의 파급**: 포스터를 다시 만들면 DesignAssets가 갱신되어 기존 규격변환 결과물이 새 원본과 어긋난다. ⑤ 화면에서 포스터를 선택할 때 "다른 홍보물도 다시 만들어야 할 수 있습니다"라고 미리 안내한다
- **비고**: MVP는 커스텀 규격 입력 UI 없음. 규격은 코드 상수로 관리한다(Stage 2·12)

### ⑥ 일괄변환 (규격별 복수안)

- **목적**: 선택한 규격마다 Recomposition을 수행해 규격별로 복수안(기본 3안)을 제시한다.
- **표시**: 규격별 탭 또는 섹션으로 구분, 각 섹션에 3안 카드
- **액션**: 규격별로 하나씩 선택 / 규격별 재생성 / 최소 객체 조정(제목·날짜·장소·출연진·사진·로고 위치·크기 이동, object_map 기반)
- **출력**: 규격별 GeneratedAsset 확정

### ⑦ 프로젝트 대시보드

- **목적**: 프로젝트의 모든 생성물을 관리하는 상시 화면. 재방문 시 진입점이기도 하다.
- **표시**: 최상단에 **대표 포스터 영역**(원본임을 명확히 드러내는 큰 카드 + "대표 포스터" 라벨 + "다시 만들기" 버튼)을 고정 배치하고, 그 아래에 규격변환 결과물 그리드를 둔다. 각 결과물에는 상태(제안됨/선택됨/보관)와 "정보 변경됨"·"원본 변경됨" 배지, 대용량 파일의 다운로드 가능 기한(만료 시 "다운로드 기간 종료")을 표시하며, 일정·장소가 미정인 프로젝트는 상단에 "일정/장소 미정" 경고 배지를 띄운다
- **액션**: 결과 확인 / 개별 선택 / 선택 다운로드 / 일괄 다운로드 / 개별 삭제 / 정보 수정(6-1로 이동) / 최신 반영(정보·원본이 바뀐 결과물 일괄 갱신) / 포스터 다시 만들기(⑤의 원본 재생성 경로로 진입) / 추가 제작 진입 / 인쇄 진입 / 프로젝트 복제
- **MVP 제약**:
  - "추가 제작" 진입은 버튼만 노출하고 Phase 3 전까지는 비활성 또는 "준비중" 처리
  - "인쇄" 진입은 활성화하여 ⑧ 인쇄 페이지로 실제 이동한다. 규격·수량·용지·옵션·배송지 입력과 예상금액 계산까지 MVP에서 제공하되, 결제·주문 접수 버튼은 클릭되지 않도록 비활성 처리한다(상세는 아래 ⑧ 참고)
  - 일정·장소가 미정인 상태로 ⑧ 인쇄 페이지에 진입하면 경고를 표시한다(강제 차단은 아님)

### ⑧ 인쇄 페이지 (규격·수량·옵션·배송지 입력 + 예상금액, 주문은 비활성)

- **목적**: 인쇄가 필요한 결과물을 실제 주문 직전까지 준비해볼 수 있게 한다. MVP는 결제·발주 연동 이전 단계까지만 제공한다.
- **인쇄 대상 제약 없음**: 프로젝트의 **모든 결과물**을 인쇄 대상으로 선택할 수 있다(포스터 포함). 특정 규격만 인쇄 가능하도록 제한하지 않는다. 다만 원본 해상도가 선택한 인쇄 규격에 비해 낮으면 "인쇄 시 화질이 떨어질 수 있습니다" 경고를 표시한다(차단은 아님)
- **입력**: 인쇄 대상 결과물 선택(generated_asset_id), 인쇄 규격, 수량, 용지, 옵션, 배송지(수령인/연락처/주소/요청사항)
- **표시**: 입력값 기준 예상 금액(PrintOrderDraft.estimated_price)
- **액션**: 입력값 수정 시 예상금액 실시간 갱신. "주문하기"/결제 버튼은 화면에 노출하되 클릭이 동작하지 않도록 비활성 처리(또는 클릭 시 "곧 지원 예정" 안내)
- **미정 상태 경고**: 프로젝트의 일정 또는 장소가 아직 미정이면 진입 시 경고 모달("일정이 아직 미정입니다. 계속 진행하시겠습니까?")을 띄운다. 확인하면 계속 진행 가능(강제 차단 아님)
- **비고**: 단가표(규격×수량×용지×옵션 → 가격)는 인쇄 협력업체와 협의 후 확정 필요. MVP는 플레이스홀더 단가로 화면을 구성한다(Stage 2 PrintOrderDraft 참고)

## 정보 수정 → 반영 시나리오 (재방문 경로)

1. 홈 대시보드에서 기존 프로젝트 클릭 → 프로젝트 대시보드(⑦) 진입
2. "정보 수정" 클릭 → 6-1 화면에서 PerformanceInfo 수정(날짜·장소·출연진 등, 미정 해제도 여기서 처리)
3. 저장 시:
   - 포스터(auto_sync_text=true): 텍스트 레이어가 즉시 자동으로 다시 렌더링됨. 별도 액션 불필요
   - 그 외 결과물: 자동으로 바뀌지 않는다. 대시보드에 "정보 변경됨" 배지가 뜨고, "최신 반영" 버튼을 눌러야 일괄 갱신된다. 갱신 시 이전 이미지 파일은 서버에서 삭제되고 같은 자리에 새 이미지로 교체된다(새 항목이 추가되는 것이 아님)
4. 아직 만들지 않은 규격을 새로 추가하고 싶다면 ⑤로 재진입해 선택

## 설계 결정 확정 (재검토 결과)

1. ① 필수 4항목은 반드시 입력해야 하며 건너뛰기는 없다. 날짜·장소는 "미정"을 선택할 수 있다(장르·공연명은 미정 불가)
2. ⑦ 대시보드의 "인쇄" 버튼은 노출·활성화하고 ⑧ 인쇄 페이지까지 MVP에서 제공한다. 단 실제 결제·주문 접수는 비활성 처리
3. ③ 시안 선택 화면의 기본 후보 개수는 Stage 5에서 **3개**로 결정됨(비용 통제 + "다른 방향 보기"로 보완 가능하다는 근거)

## 설계 결정 확정 (추가 반영, 이번 라운드)

1. ④(시안확정) 직후 바로 ⑤(규격선택)로 넘어가지 않을 수 있다는 점을 반영해 ④-1(다음 행동 선택) 화면을 새로 추가함
2. 정보 변경 반영 방식을 이원화함 — 포스터는 자동 반영(같은 파일 교체), 그 외 결과물은 "최신 반영" 버튼으로 수동 일괄 반영(이전 파일 삭제 후 교체). Stage 2 GeneratedAsset.auto_sync_text 참고
3. 미정 상태(일정·장소)는 홍보물에는 대체 문구로 렌더링하고, ⑧ 인쇄 페이지 진입 시에는 경고를 표시(강제 차단은 아님)
4. 대시보드에 결과물 개별 삭제, 대용량 파일 다운로드 가능 기한 표시, 프로젝트 복제 기능을 추가함

## 설계 결정 확정 (정합성 검토 반영)

1. **페이지 구조**: 비로그인 첫 화면은 소개 페이지, 로그인 후 첫 화면은 홈 대시보드(프로젝트 목록)로 확정. 신규 생성 플로우는 홈 대시보드의 "새 프로젝트 만들기" 버튼에서 시작한다
2. **결과물 삭제**: 소프트 삭제 후 30일 뒤 하드 삭제(Stage 2 참고)
3. **대용량 파일 다운로드 기한**: 원본은 생성일 + 90일까지만 다운로드 가능. 이후에도 미리보기 이미지로 결과물을 확인할 수 있다(Stage 6)
4. **인쇄 대상**: 제약 없음. 포스터를 포함한 모든 결과물을 인쇄 주문 대상으로 선택 가능하며, 해상도 부족 시 경고만 표시
5. **프로젝트 생성 시점**: ① 진입 시 draft로 즉시 생성, ④에서 active로 확정(Stage 2 참고)
6. **포스터의 위치**: ⑤에 "원본 다시 만들기"로 남기되 확정 시 기존 포스터를 교체하는 방식으로 중복을 막고, ⑦ 대시보드에서는 대표 이미지임이 드러나도록 최상단에 별도 영역으로 배치한다. 이로써 포스터 재생성 경로도 함께 확보된다

# 외부 기술·API 총정리 (Stage 14)

> 흩어져 있던 외부 의존을 한 곳에 모았다. 계정 발급, 비용 산정, 라이선스 검토, 장애 대응 계획의 기준 문서다.

## 원칙 — 무엇을 사고 무엇을 만드는가

ACTSET은 **자체 AI 모델을 만들지 않는다.** 모델은 사서 쓰고, 대체 불가능한 자산은 도메인 지식 쪽에 쌓는다.

| 자체 핵심기술 (직접 만든다) | 외부 활용 (가져다 쓴다) |
|---|---|
| 공연정보 구조화(Role Schema) | 이미지 생성 |
| 장르별 배치기준(Genre Rules) | 레이어 분해 |
| 규격별 Recomposition | OCR·VLM·세그멘테이션 |
| 프로젝트 관리·정보 변경 반영 | LLM |
| 선택데이터 기반 추천 | 스토리지·GPU 실행 환경 |
| **텍스트 레이어 렌더링(Java2D)** | |
| **업로드 사진 레이어 합성(Java2D)** | |

텍스트 렌더링을 자체 구현 쪽에 둔 것이 중요하다. 결과물의 정확성이라는 핵심 요구가 외부 벤더에 걸리지 않는다.

**업로드 사진도 같은 쪽에 있다.** 출연진·공연 사진은 외부 AI API로 전송하지 않고 자체 엔진이 PHOTO 레이어로 합성한다(Stage 5). 얼굴이 담긴 개인정보가 해외로 나가지 않으므로 국외이전 부담이 사진에 대해서는 발생하지 않는다.

## 1. 상용 API (계정·과금 필요)

### 1-1. 이미지 생성 — Ideogram 4.0

| 항목 | 내용 |
|---|---|
| 용도 | 배경·키비주얼 생성 (글자 없는 순수 비주얼) |
| 과금 | 이미지 장당. 구독 없음 |
| 단가 | Turbo $0.03 / **Default $0.06** / **Quality $0.10** |
| 사용처 | ③ 시안 후보 생성, ⑤ 포스터 재생성, 아웃페인팅(검토 중) |
| 호출량 | 시안 1세트 = 3장 |

**운용 전략**: 후보는 Default로 뽑고 확정본만 Quality로 다시 생성한다. 버려질 후보에 비싼 단가를 쓰지 않는다. 두 티어의 결과 차이는 PoC에서 확인 후 결정한다.

**필수 확인 사항 (E0)**
- 요금제별 **상업적 이용 권한** — 결과물이 인쇄되어 공연장에 걸리고 예매처에 게시된다
- **생성물 소유권** 조항 — 플랜에 따라 생성물이 공개 갤러리에 노출되는 경우가 있다
- **전송 데이터의 학습 이용 여부**와 옵트아웃 가능성
- 한국어 지원은 문서에 명시되어 있지 않으나, **글자를 맡기지 않으므로 문제가 되지 않는다.** 오히려 배경에 글자가 섞이지 않도록 억제하는 것이 과제(PoC Q1)

### 1-2. LLM — GPT-5.6

| 항목 | 내용 |
|---|---|
| 용도 | 공연정보 구조화 보조, 카피·상세페이지·프로그램 설명 생성 |
| 사용처 | MVP에서는 최소 범위(소개문 다듬기). 본격 활용은 Phase 4(상세페이지) |
| 과금 | 토큰 단위 |

**MVP에서의 역할이 작다는 점을 분명히 해둔다.** ACTSET의 핵심 기능인 배치·규격변환은 LLM이 아니라 자체 엔진이 처리한다. LLM 비중이 커지는 것은 Phase 4 이후다.

**확인 사항**: 입력 데이터의 학습 이용 여부, 국외이전 고지(소개문·시놉시스에 출연진 이름이 담길 수 있다 — Stage 15). **사진은 전송 대상이 아니다.**

### 1-3. AI 타이포그래피 — Qwen-Image-3.0 (선택 기능)

| 항목 | 내용 |
|---|---|
| 용도 | 타이틀 모드 B — 공연명 타이포그래피를 이미지로 생성 |
| 특징 | **한국어 포함 12개 언어** 텍스트 렌더링 지원 |
| 사용처 | 사용자가 모드 B를 선택했을 때만 |

**연동 시 반드시 지킬 규칙 두 가지**

1. 문자열을 **따옴표로 정확히 감싼다.** 설명형으로 쓰면 모델이 문구를 임의로 바꾼다
2. **프롬프트 자동 확장을 끈다.** 켜져 있으면 문구가 재작성된다

공연명이 바뀌면 안 되는 서비스이므로 두 규칙을 연동 코드에서 강제한다. 기본 모드(폰트 렌더링)가 있으므로 이 기능이 실패해도 서비스에 지장은 없다.

## 2. 오픈소스 모델 (서버리스 GPU로 실행)

모두 GPU가 필요하므로 애플리케이션에 넣지 않고 **HTTP 엔드포인트로 호출**한다. 상시 가동이 불필요한 배치성 작업이라 서버리스 GPU(Replicate·Modal 등)가 적합하다.

| 모델 | 용도 | 사용 시점 | 대체 가능성 |
|---|---|---|---|
| **Qwen-Image-Layered** | **생성 이미지**를 RGBA 레이어(배경판·피사체·장식)로 분해 — 고객 업로드 사진은 대상이 아니다 | ④ 확정 시 **1회**, 포스터 재생성 시 | 실패 시 SAM2 절충안 |
| **SAM2** | 인물·오브젝트 영역 분리 | 학습 파이프라인, 레이어 분해 폴백 | — |
| **Qwen2.5-VL** | 포스터 요소의 **역할 판정**(제목/날짜/장소/출연진) | 학습 파이프라인, 참고 이미지 분석 | — |
| **Tesseract OCR** | 텍스트 추출 (Apache 2.0) | 학습 파이프라인 | PaddleOCR과 비교 후 택일 |
| **PaddleOCR** | 텍스트 + 문서 구조 인식. 다국어 강점 | 학습 파이프라인 | Tesseract와 비교 후 택일 |
| **아웃페인팅 모델** | 배경판 좌우 확장 (가로 긴 규격) | ⑥ 규격 변환 | **미선정** — PoC Q4에서 결정 |
| **업스케일러** | 비주얼 레이어를 인쇄 해상도로 확대 | ⑧ 인쇄 | **미선정** |

**Qwen-Image-Layered가 가장 중요하다.** 규격 변환 전략 전체가 이 모델의 분해 품질에 걸려 있다(PoC Q6). 실패하면 SAM2로 피사체만 분리하는 절충안이나 규격별 배경 별도 생성으로 후퇴해야 한다.

**OCR 2종은 비교 후 하나만 쓴다.** 둘 다 유지할 이유가 없다.

## 3. 인프라

| 영역 | 선택 | 비고 |
|---|---|---|
| DB | **AWS RDS (PostgreSQL)** | 서울 리전 |
| 파일 저장 | **AWS S3** 또는 Cloudflare R2 | 서명 URL 발급 |
| 서버리스 GPU | Replicate · Modal 등 | 미선정 |
| 애플리케이션 배포 | 컨테이너 (Fly.io · Render · AWS) | 미선정 |
| **메일 발송** | AWS SES 등 | **미선정 — 비밀번호 재설정의 전제** |
| 결제(Phase 6) | 국내 PG | 미선정 |

리전은 RDS·S3 모두 서울(ap-northeast-2)로 맞춰 전송 지연과 비용을 줄인다.

## 4. 라이브러리·폰트

| 항목 | 선택 | 라이선스 |
|---|---|---|
| 이미지 렌더링 | **Java2D** (JDK 표준) | 별도 의존 없음 |
| 인쇄 PDF | **Apache PDFBox** | Apache 2.0 |
| 한글 폰트 | **Pretendard** 또는 **Noto Sans KR** | SIL OFL — 상업 이용·임베딩 허용 |

폰트는 서버 렌더링과 인쇄물 사용이 모두 걸리므로 라이선스 확인 항목이 일반 웹폰트보다 많다. SIL OFL은 폰트 파일 자체를 유료 판매하는 것만 금지하므로 이 서비스의 사용 형태와 충돌하지 않는다.

## 5. 비용이 발생하는 지점

| 지점 | 비용 | 통제 수단 |
|---|---|---|
| 시안 3안 생성 | 약 250원 (Default) | 크레딧 차감 |
| 포스터 재생성 | 약 250원 + 레이어 분해비 | 크레딧 차감 |
| 규격 변환 | 0원 ~ 85원 (아웃페인팅 여부에 따라) | 크레딧 차감 |
| 레이어 분해 | **미측정** (PoC Q6) | ④ 확정 시 1회로 제한 |
| 텍스트 재렌더링 | 0원 | 무과금 |
| 스토리지 | 용량 비례 | 대용량 원본 90일 만료 |

**베타 기간이 위험 구간이다.** 크레딧을 관리자가 넉넉히 지급하므로 크레딧이 실질 통제 수단이 되지 못한다. 계정별·전체 일일 호출 상한을 별도로 두어야 한다(Stage 15).

## 6. 벤더 종속과 대체 경로

| 의존 | 종속 정도 | 대체 |
|---|---|---|
| Ideogram | **높음** — 단일 벤더. 장애 시 시안 생성 전면 중단 | 다른 이미지 생성 API로 교체 가능하나 결과 톤이 달라짐 |
| Qwen-Image-Layered | **높음** — 규격 변환 전략의 전제 | SAM2 절충안 |
| GPT-5.6 | 낮음 — MVP에서 역할이 작다 | 다른 LLM으로 교체 용이 |
| OCR·VLM | 낮음 — 배치 작업이라 지연 허용 | 상호 대체 가능 |
| AWS | 보통 | 표준 인터페이스(S3 호환)라 이전 가능 |

**설계 원칙**: 외부 기술은 어댑터 뒤에 두고 도메인 로직이 벤더 SDK에 직접 의존하지 않게 한다. 벤더가 바뀌어도 자체 핵심기술 5가지는 그대로 남아야 한다.

## 7. E0에서 확인해야 할 것

| 항목 | 왜 |
|---|---|
| Ideogram 요금제의 상업 이용·소유권 조항 | 결과물이 상업적으로 인쇄·게시된다 |
| 각 벤더의 학습 데이터 이용 정책 | 고객의 미공개 공연정보 텍스트와 **참고 이미지**가 전송된다 (출연진·공연 사진은 전송하지 않는다 — Stage 5) |
| 해외 API 전송에 따른 국외이전 고지 대상 | 소개문·시놉시스의 출연진 이름 등 텍스트 + **참고 이미지(VLM 분석)**(Stage 15). 출연진·공연 사진은 설계상 나가지 않는다 |
| 폰트 라이선스 (서버 렌더링·인쇄물) | 무료 폰트로 충분한지 확인 |
| 서버리스 GPU 벤더 선정 + 콜드스타트 실측 | 레이어 분해 지연이 ④ 확정 UX를 좌우한다 |
| 메일 발송 서비스 선정 + 발신 도메인 인증 | 비밀번호 재설정의 전제 |
| 아웃페인팅·업스케일 모델 선정 | PoC Q4·Q5 |

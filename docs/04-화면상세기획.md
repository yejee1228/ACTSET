# 화면별 상세기획 (Stage 4)

## 목적

Stage 3(IA)에서 정의한 화면 목록을 실제 UI 컴포넌트·상태·인터랙션 수준으로 구체화한다. 이 문서가 확정되어야 Stage 7(개발마일스톤)에서 화면 단위 개발 티켓을 뽑을 수 있다.

## 공통 UI 원칙

1. **선택 중심 UX**: 사용자가 직접 그리거나 배치하는 화면은 최소화하고, 후보 중 고르는 화면이 중심이다(③, ⑥).
2. **최소 편집만 허용**: 자유 편집 캔버스가 아니라 객체(제목/날짜/장소/출연진/사진/로고) 단위의 위치·크기 조정만 제공한다(⑥의 "편집" 모드).
3. **디바이스 가정**: 정보 입력·시안 검토는 데스크톱 사용을 우선 가정한다(기획자가 여러 정보를 다루는 작업). 반응형 대응 우선순위는 Stage 7에서 별도 결정.
4. **자동저장은 신규 입력에만**: 신규 생성 플로우(①·②)에서는 입력 중 이탈해도 데이터가 유실되지 않도록 draft 프로젝트에 필드 단위로 자동저장한다. 반면 **정보 수정 화면(6-1)은 명시적 "저장" 버튼**을 사용한다 — 저장 시 포스터가 자동 재렌더링되므로 자동저장을 적용하면 한 글자 입력할 때마다 이미지 생성이 반복되어 비용과 서버 부하가 통제되지 않는다.

---

## 0-A. 소개 페이지 (비로그인 첫 화면)

- **목적**: 서비스를 처음 접한 방문자에게 무엇을 해주는 서비스인지 알리고 가입·로그인으로 유도한다.
- **구성요소**: 서비스 소개(공연 하나 등록 → 전 규격 홍보물 자동 생성), 예시 결과물, 로그인/회원가입 버튼
- **전환**: 로그인/회원가입 → 0-B 홈 대시보드
- **비고**: 이미 로그인된 사용자가 접근하면 0-B로 자동 이동한다

## 0-B. 홈 대시보드 (로그인 후 첫 화면)

- **목적**: 로그인 직후 도착하는 계정 단위 화면. 내 프로젝트 목록을 보여주고 모든 작업의 시작점이 된다.
- **용어 주의**: 여기서 말하는 "대시보드"는 계정 단위 화면이며, ⑦의 "프로젝트 대시보드"(공연 하나의 생성물 관리 화면)와 다르다.
- **구성요소**
  | 요소 | 설명 |
  |---|---|
  | 새 프로젝트 만들기 버튼 | 클릭 시 ①로 이동 — 신규 생성 플로우의 유일한 진입점 |
  | 프로젝트 카드 목록 | 카드별 대표 썸네일(DesignAssets.key_visual_image), 공연명, 날짜(미정이면 "일정 미정" 표기), 마지막 수정일 |
  | 카드 메뉴(⋮) | 열기(⑦로 이동) / 복제(새 프로젝트 생성 — PerformanceInfo·DesignAssets 복사, 일정은 미정으로 초기화) / **삭제**(확인 모달 → 소프트 삭제. 30일간 복구 가능함을 안내) |
  | 정렬/검색 | 최근 수정순 기본, 공연명 검색 |
- **상태**: 빈 상태(프로젝트 0개 — "첫 공연을 등록해보세요" + 신규 버튼 강조) / 목록 상태
- **전환**: 카드 클릭 → ⑦ 프로젝트 대시보드로 이동 (① ~ ④-1를 다시 거치지 않음). 복제 클릭 → 새 프로젝트 생성 후 ⑦로 이동

## 1. 공연 정보 입력 (①)

- **목적**: 필수 4항목만 빠르게 확정한다.
- **구성요소**
  | 요소 | 타입 | 비고 |
  |---|---|---|
  | 장르 선택 | 7개 카드형 단일선택 | 미정 불가, 미선택 시 다음 버튼 비활성 |
  | 공연명 | 텍스트 입력 | 미정 불가, 공백 불가 |
  | 장소 | 텍스트 입력 + "장소 미정" 체크박스 | 체크 시 입력창 비활성화, venue.is_undetermined=true |
  | 날짜 | 날짜 선택 + "날짜 미정" 체크박스 | 체크 시 날짜선택 비활성화, sessions[0].is_undetermined=true |
- **유효성 검사**: 4항목 모두 값이 있어야(또는 해당 필드의 미정 체크) 다음 버튼 활성화
- **처리**: 화면 진입 시 draft 프로젝트를 생성하고, 이후 입력값을 필드 단위로 자동저장한다(Stage 2 Project 참고)
- **전환**: 다음 → ②로 이동 (건너뛰기 없음)

---

## 2. 추가정보 입력 (②)

- **목적**: 선택 정보를 그룹별로 나눠 입력받되, 채우지 않아도 다음으로 진행 가능.
- **레이아웃**: 좌측에 9개 그룹 아코디언(또는 세로 탭), 그룹별 완료 여부를 체크 아이콘으로 표시
- **그룹 구성**: 일정 상세 / 부가 정보 / 출연진 / 가격 / 주최 정보 / 안내 / 소개 / 이미지·색상 / 문구·이미지 방향 (Stage 3 표 참조)
- **그룹별 특이 UI**
  - 출연진(cast): 행 추가형 리스트(이름/역할/사진 업로드/경력), 드래그로 순서 변경. 사진 업로드란에는 "사진은 외부 AI로 전송되지 않고 홍보물에 그대로 배치됩니다" 안내 문구를 표기(Stage 5 원칙, 신뢰 요소). 경력(career) 입력란은 기본은 접혀있고 필요 시 펼쳐서 작성(클래식 등 경력 표기가 흔한 장르는 Stage 5에서 기본 노출로 전환 검토)
  - 가격(price_items): "좌석등급 추가" / "시점별 가격 추가" / "할인 추가" 3개 버튼으로 유형별 행 추가, 각 행은 category에 따라 입력 필드가 달라짐(할인은 condition_note 필수 노출)
  - 주최 정보: 주최/주관/후원 3개 입력란을 각각 별도 섹션으로 분리, 각각 복수 입력 가능(태그 입력형)
  - 이미지·색상: 업로드 슬롯별 안내를 구분한다 — 공연사진·로고는 "외부 AI로 전송되지 않고 홍보물에 그대로 배치됩니다", **참고 이미지는 "스타일 분석을 위해 외부 AI로 전송됩니다. 인물 사진은 넣지 말아주세요"**(Stage 5·15)
  - 문구·이미지 방향: mandatory_notices는 태그/리스트 입력, image_direction_note는 자유 텍스트영역(placeholder 예시: "차분한 블루톤, 인물 사진은 크게")
- **액션**: 이전(①로) / 다음(③ 시안 생성으로) — 그룹 전체 스킵 가능
- **전환**: 다음 → 시안 생성 요청 → ③으로 이동(로딩 상태 경유)

---

## 3. 시안 선택 화면 (③)

- **목적**: 기본 시안 후보를 제시하고 방향을 좁힌다.
- **구성요소**
  | 요소 | 설명 |
  |---|---|
  | 후보 카드 | 이미지 미리보기 + "선택" 버튼 |
  | 다른 방향 보기 | 현재 후보 세트를 새로운 스타일 세트로 교체 |
  | 재생성 | 같은 방향을 유지한 채 새 후보 생성(카드 개수 유지) |
  | 이 방향으로 더 보기 | 특정 카드에 hover/롱프레스 시 노출되는 보조 액션, 해당 스타일과 유사한 후보 추가 생성 |
- **상태**: 로딩(첫 생성 중 스켈레톤) / 결과 표시 / 재생성 중(기존 카드 유지 + 부분 로딩)
- **인터랙션 로깅**: 위 4개 액션 전부 SelectionEvent로 기록(Stage 2 참고). 액션 실행 시점의 화면에 표시 중인 후보 전체를 shown_candidates로 함께 저장
- **전환**: "선택" 클릭 → 간단한 확정 인터스티셜(④, 아래 참조)로 이동

## 3-1. 시안 확정 (④, 인터스티셜)

- **목적**: 선택한 시안으로 draft 프로젝트를 확정하는 짧은 확인 단계. 별도 페이지라기보다 모달/전환 화면에 가깝다.
- **표시**: 선택한 시안 미리보기 + "이 디자인으로 프로젝트를 시작할까요?" 확인
- **액션**: 확정(Project.status를 active로 전환, DesignAssets 저장, 선택 후보를 포스터로 승격) / 취소(③으로 복귀)
- **전환**: 확정 → 3-2(④-1)로 이동

## 3-2. 프로젝트 생성 완료 — 다음 행동 선택 (④-1)

- **목적**: 시안 확정 직후 바로 규격 변환으로 이어가지 않을 수 있다는 점을 반영한 화면. 프로젝트가 만들어졌음을 알리고 다음 행동을 사용자가 고르게 한다.
- **구성요소**: "프로젝트가 생성되었습니다" 안내 문구 + 확정된 포스터 미리보기 + 버튼 2개
- **액션**: "대시보드로 가기"(⑦로 이동) / "지금 홍보물 만들기"(⑤로 이동)

---

## 4. 홍보물 생성 페이지 — 규격 선택 (⑤)

- **목적**: 기본 규격 중 필요한 것을 복수 선택한다.
- **구성요소**: 4개 섹션으로 그룹핑한 체크박스 목록(각 항목에 규격 비율 미리보기 아이콘, 픽셀 치수 표기)
  - **원본(1종)**: "포스터 다시 만들기" — 시각적으로 구분된 별도 영역에 배치하고, 현재 포스터 썸네일과 "이 포스터를 기준으로 나머지 규격이 만들어집니다" 설명을 함께 노출한다. 체크 시 "다른 홍보물도 다시 만들어야 할 수 있습니다" 경고 문구를 인라인으로 표시
  - **예매처(3종)**: NOL티켓, 티켓링크, 플레이티켓 — 자기가 쓰는 예매처만 고르면 되도록 묶어 보여준다
  - **온라인(7종)**: SNS 1:1, SNS 4:5, 스토리, 홈페이지 썸네일, 홈페이지 배너, DID, 공연장 모니터
  - **오프라인(2종)**: 현수막, X배너
- **포스터 선택 시 동작**: ⑥에서 새 안을 확정하면 결과물이 추가되는 것이 아니라 기존 포스터가 교체되고 DesignAssets가 갱신된다(Stage 2 참고). 다른 규격 결과물에는 "원본 변경됨" 배지가 붙는다
- **액션**: 전체 선택 / 선택 해제 / "일괄변환 생성" 버튼(1개 이상 선택해야 활성화)
- **전환**: 일괄변환 생성 → ⑥으로 이동(로딩 경유)

---

## 5. 일괄변환 결과 화면 (⑥)

- **목적**: 선택한 규격마다 복수안을 제시하고 확정한다.
- **레이아웃**: 규격별 탭(또는 세로 섹션), 탭당 3안 카드
- **구성요소**
  | 요소 | 설명 |
  |---|---|
  | 변형 카드(3안) | 각 카드에 "선택" 버튼 |
  | 규격별 재생성 | 해당 규격만 다시 생성 |
  | 편집 모드 | 선택된 카드에서 진입, object_map 기반으로 제목/날짜/장소/출연진/사진/로고를 바운딩박스로 표시해 위치 이동·크기 조정만 허용(텍스트 직접 수정·새 요소 추가는 불가) |
- **인터랙션 로깅**: 규격별 선택 액션도 SelectionEvent(screen=규격변환)로 기록
- **진행 표시**: 전체 선택 규격 중 확정된 규격 수 표시(예: "5/8 규격 확정")
- **전환**: 모든 규격 확정(또는 "나중에 마저 하기") → ⑦ 프로젝트 대시보드로 이동

---

## 6. 프로젝트 대시보드 (⑦)

- **목적**: 프로젝트의 모든 생성물을 관리하는 상시 화면.
- **레이아웃**: 3단 구성 — ① 상단 공연 요약 정보(공연명·날짜·장소, 정보 수정 진입 버튼) ② **대표 포스터 영역** ③ 규격변환 결과물 그리드
- **대표 포스터 영역(신설)**: 포스터가 프로젝트의 원본이자 대표 이미지임이 한눈에 드러나도록 그리드와 분리해 배치한다.
  - 다른 결과물 카드보다 크게 표시하고 "대표 포스터" 라벨을 붙인다
  - 영역 설명: "이 포스터를 기준으로 모든 홍보물이 만들어집니다"
  - 카드 액션: 다운로드 / 인쇄 / **다시 만들기**(⑤의 원본 재생성 경로로 이동)
  - 그리드의 다른 카드와 달리 삭제 버튼을 제공하지 않는다(원본이 없으면 변환 기준이 사라지므로)
- **구성요소**
  | 요소 | 설명 |
  |---|---|
  | 생성물 그리드 | 규격변환 결과물의 썸네일, 상태 배지(제안됨/선택됨/보관), "정보 변경됨"·"원본 변경됨" 배지 |
  | 필터 | 카테고리별(포스터/규격변환/추가제작물) 필터 |
  | 체크박스 선택 | 개별/전체 선택 |
  | 다운로드 | 선택 다운로드 / 일괄 다운로드(zip). 대용량 원본 카드에는 "다운로드 가능 기한: YYYY-MM-DD" 라벨을 표시하고, 기한이 지나면 "다운로드 기간 종료"로 바꾸고 버튼을 비활성화한다. **썸네일은 그대로 보인다**(미리보기는 영구 보관) |
  | 개별 삭제 | 생성물 카드마다 삭제 버튼. 확인 모달 후 소프트 삭제되어 목록에서 사라지며, 30일 뒤 파일까지 영구 삭제됨(Stage 2 삭제 정책) |
  | 최신 반영 | "정보 변경됨" 또는 "원본 변경됨" 배지가 있는 결과물이 1개 이상이면 노출되는 일괄 버튼. 클릭 시 대상 결과물 전체를 다시 렌더링(이전 파일 삭제 후 교체). 원본 변경이 포함된 경우 Recomposition을 다시 수행해 크레딧 소비가 크므로 실행 전 확인 모달로 안내 |
  | 미정 경고 배지 | 프로젝트 상단에 "일정 미정"/"장소 미정" 배지. 클릭 시 6-1(정보 수정)로 이동 |
  | 정보 수정 | 클릭 시 6-1 화면으로 이동 |
  | 추가 제작 | MVP에서는 비활성 배지("곧 지원") 표시, Phase 3부터 활성화 |
  | 인쇄 | 활성화. 클릭 시 인쇄 대상 결과물 선택 후 ⑧로 이동 |
- **전환**: 정보 수정 → 별도 화면(아래 6-1) / 인쇄 → ⑧ / 신규 규격 추가 → ⑤로 재진입

## 6-1. 정보 수정 화면 (① + ②form 재사용)

- **목적**: 기존 PerformanceInfo를 수정한다.
- **레이아웃**: ②와 동일한 그룹 구성. 다만 여기서는 필수 4항목(①)도 같은 화면에서 함께 수정 가능하도록 상단에 노출(신규 생성 때는 ①·②로 나눴지만, 수정 시점에는 한 화면에서 전부 다룬다). 날짜·장소가 미정이었다면 여기서 "미정" 체크를 해제하고 실제 값을 입력해 확정할 수 있다
- **액션**: 저장 → ⑦로 복귀. 저장 시 안내 문구로 반영 방식을 명시("포스터는 자동으로 반영돼요. 다른 홍보물은 대시보드에서 [최신 반영]을 눌러야 새 정보로 바뀌어요")

## 7. 인쇄 페이지 (⑧)

- **목적**: 인쇄 주문을 결제 직전까지 준비한다.
- **레이아웃**: 좌측 입력 폼 + 우측 실시간 예상금액 패널
- **구성요소**
  | 요소 | 설명 |
  |---|---|
  | 인쇄 대상 | ⑦에서 선택해온 결과물 미리보기(변경 가능). 포스터를 포함한 프로젝트의 모든 결과물을 대상으로 선택할 수 있으며 규격에 따른 제한은 없음 |
  | 해상도 경고 | 선택한 결과물의 원본 해상도가 인쇄 규격에 비해 낮으면 "인쇄 시 화질이 떨어질 수 있습니다" 경고 표시(주문 차단은 아님) |
  | 인쇄 크기 | 프리셋(A4·A3·현수막 등) 선택 또는 mm 직접 입력. **규격에 따른 제한 없음** |
  | 수량/용지/옵션 | 드롭다운·수량 입력 |
  | 배송지 | 수령인/연락처/주소/요청사항 |
  | 예상금액 패널 | 입력값 변경 시 실시간 갱신(PrintOrderDraft.estimated_price) |
  | 주문하기 버튼 | 항상 노출되지만 비활성 상태(hover 시 "곧 지원 예정" 툴팁) |
- **미정 상태 경고**: 프로젝트의 일정 또는 장소가 미정이면 진입 시 경고 모달("일정이 아직 미정입니다. 계속 진행하시겠습니까?")을 띄운다. 확인 시 계속 진행 가능(강제 차단 아님)
- **전환**: 없음(MVP 최종 화면). 뒤로가기로 ⑦ 복귀만 가능

## 확인이 필요한 사항

1. ④(시안 확정)를 별도 페이지가 아닌 인터스티셜(모달)로 설계했는데, 실제 구현 난이도상 별도 라우트로 분리하는 편이 나을 수도 있음 — Stage 7에서 개발 편의로 재판단
2. ⑥ 편집 모드(object_map 기반 위치·크기 조정)의 구체적 인터랙션(드래그 스냅, 그리드 가이드 등)은 실제 프로토타입 제작 시 세부 조정 필요
3. ②/6-1의 그룹 아코디언 UI는 텍스트 기획이라 실제 느낌 확인이 어려움 — 필요하면 design skill로 와이어프레임 목업을 별도 제작 가능
4. 만료된 결과물의 재생성 동선 — 미리보기만 남은 카드에서 "다시 만들기"로 바로 재생성할 수 있게 할지 확인 필요(크레딧 소비)
5. 소프트 삭제된 결과물을 30일 이내에 사용자가 직접 되살릴 수 있는 복구 UI(휴지통)를 MVP에 넣을지 결정 필요 — 데이터상으로는 복구가 가능한 상태로 남는다

# 텍스트 재조판 후보 폰트 — 라이선스 확인표 (2026-10-09)

회사 보유 라이선스 폰트는 없다(사용자 확인). 그래서 **상업 사용 + 서버 임베딩("웹사이트 및 프로그램 서버 내 폰트 탑재") 허용**이 확인된 무료 폰트만 후보에 넣는다.
우리 사용 방식: 서버에 폰트를 두고 글자를 그려 그 이미지를 고객에게 준다(폰트 파일은 배포하지 않는다).

확인 출처는 산돌구름 무료 폰트 페이지의 라이선스 요약표다(저작권자 원문 요약). **사용 전 저작권자의 최신 라이선스를 다시 확인한다.**
파일은 원본 보관 저장소 github.com/fonts-archive 에서 받는다(`bash poc/fonts_download.sh`).

**이번에 넣지 않은 것**
- 페이퍼로지: 라이선스 원문을 확인하지 못했다
- 에스코어 드림: 상업 사용·임베딩 허용 확인(https://www.sandollcloud.com/free-font/778/S-CoreDream)이나 보관 저장소에 TTF가 없어 다음에 추가

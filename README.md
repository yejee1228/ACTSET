# ACTSET

> 공연 하나를 등록하면, 필요한 홍보물을 계속 꺼내 쓰는 공연 특화 AI 홍보물 제작 플랫폼

ACTSET은 공연정보를 한 번 등록하면 AI와 공연 특화 레이아웃 엔진을 이용해 포스터부터 규격별 홍보물, 추가 이미지, 상세페이지, 리플렛, 프로그램북까지 제작하고 최종 인쇄까지 연결하는 공연 특화 홍보물 제작 플랫폼입니다.

ACTSET의 목표는 단순히 이미지를 생성하는 것이 아니라, 공연 준비 과정에서 반복되는 홍보물 제작 업무 전체를 하나의 프로젝트 안에서 관리하고 재사용할 수 있게 만드는 것입니다.

---

## 1. 문제 정의

공연 한 편을 홍보하려면 포스터 한 장만 필요한 것이 아닙니다.

실제 공연 준비 과정에서는 다음과 같은 다양한 홍보물이 반복적으로 필요합니다.

- 메인 포스터
- SNS 1:1 / 4:5 / Story
- 예매처 대표 이미지
- 홈페이지 썸네일 / 배너
- DID
- 공연장 모니터
- 현수막
- X배너
- 캐스트 소개
- 티켓오픈 이미지
- 할인 안내
- 카드뉴스
- 공연 상세페이지
- 리플렛
- 프로그램북
- 현장 안내물
- 인쇄용 PDF

기존 방식은 크게 세 가지가 있습니다.

| 방식 | 장점 | 한계 |
|---|---|---|
| 전문 디자이너 외주 | 높은 품질 | 비용, 대기시간, 수정비, 추가 규격 비용 |
| Canva / 미리캔버스 | 직접 제작 가능 | 사용자가 직접 디자인과 배치를 판단해야 함 |
| 생성형 이미지 AI | 빠른 이미지 생성 | 정확한 공연정보 관리, 반복 수정, 규격 변환, 인쇄 연결에 한계 |

ACTSET은 이 문제를 **공연 프로젝트 단위의 구조화된 데이터와 레이어 기반 재구성**으로 해결합니다.

## 2. 핵심 가치

ACTSET의 핵심 원칙은 다음과 같습니다.

> 생성형 AI는 그림을 만들고, ACTSET은 공연 홍보물을 만든다.

사용자 관점에서는 다음 한 문장으로 설명할 수 있습니다.

> 공연 하나를 등록하면, 필요한 홍보물을 계속 꺼내 쓰는 서비스

ACTSET이 제공하는 핵심 가치는 다음과 같습니다.

### 반복 입력 제거

공연명, 날짜, 장소, 출연진, 가격, 주최·주관, 문의처 등의 정보를 한 번 등록하고 모든 홍보물에 재사용합니다.

### 선택 중심 UX

사용자가 프롬프트를 잘 쓰거나 디자인을 직접 하지 않아도 됩니다.

`적게 입력 → 결과 확인 → 선택 → 완성`

방식으로 작업합니다.

### 일관된 디자인 유지

한 공연 프로젝트 안에서 포스터, SNS, 배너, 상세페이지, 인쇄물이 동일한 톤앤매너를 유지합니다.

### 빠른 수정

날짜, 장소, 출연진 등이 변경되어도 전체 홍보물을 처음부터 다시 만들지 않고 필요한 부분만 갱신합니다.

### 제작시간 절감

ACTSET은 기존 수작업 방식 대비 홍보물 제작시간을 **80% 이상 단축**하는 것을 사업화 검증 목표로 두고 있습니다.

## 7. 레이어 기반 아키텍처

ACTSET의 핵심은 결과물을 한 장의 이미지로만 취급하지 않는다는 점입니다.

기본 렌더링 레이어는 다음과 같습니다.

```text
BACKDROP
  ↓
SUBJECT
  ↓
DECOR
  ↓
PHOTO
  ↓
TITLE
  ↓
INFO
  ↓
MARK
```

### BACKDROP
배경

### SUBJECT
주요 피사체

### DECOR
장식 요소

### PHOTO
고객이 업로드한 공연사진 / 출연진사진

### TITLE
공연명

### INFO
날짜, 장소, 가격, 출연진, 문의 등 정확한 공연정보

### MARK
로고

시안이 확정되면 비주얼을 한 번 레이어로 분해하고, 이후 규격변환에서는 저장된 레이어를 재배치합니다.

이 때문에 규격이 바뀔 때마다 전체 이미지를 다시 생성할 필요가 없습니다.

## 8. 텍스트 처리 원칙

ACTSET은 정확한 공연정보를 생성형 이미지 모델에 맡기지 않습니다.

### 기본 모드

- TITLE / INFO를 Java2D로 직접 렌더링
- 오타 없이 정확한 문자열 유지
- 날짜 / 장소 변경 시 빠른 재합성
- 인쇄용 고해상도 렌더링 가능

### 선택 모드

- Qwen-Image-3.0을 활용한 AI 타이포그래피
- 표현력이 필요한 타이틀에 한정
- 기본 기능이 아니라 선택 기능

즉, 특정 이미지 생성 모델의 한국어 렌더링 성능이 서비스 핵심 기능에 영향을 주지 않도록 설계합니다.

## 9. 고객 사진 처리

출연진 사진과 공연사진은 외부 생성형 AI API로 전송하지 않습니다.

ACTSET 자체 엔진이 PHOTO 레이어로 직접 합성합니다.

이를 통해 다음을 확보합니다.

- 얼굴 변형 방지
- 원본 화질 유지
- 개인정보 외부전송 최소화
- 규격별 자유로운 재배치

참고 이미지는 스타일 분석을 위해 외부 VLM에 전달될 수 있으며, 이 경우 별도 고지 정책을 적용합니다.

## 10. 규격 변환 엔진

ACTSET의 규격 변환은 단순 리사이징이 아닙니다.

규격이 바뀌면 다음을 다시 판단합니다.

- 제목 크기 / 위치
- 정보 우선순위
- 이미지 크롭
- SUBJECT 위치
- 로고 위치
- 정보 삭제 / 축약
- 배경 확장
- 여백

기본 규격은 다음과 같은 비율 유형으로 관리합니다.

- TALL
- EXTRA_TALL
- SQUARE
- WIDE
- EXTRA_WIDE
- ULTRA_WIDE

규격 이름 자체가 아니라 화면 비율을 기준으로 규칙을 적용하기 때문에 향후 커스텀 규격으로 확장하기 쉽습니다.

## 15. 비즈니스 모델

기본 BM은 사용량 기반 크레딧 모델입니다.

```text
무료 가입
  ↓
웰컴 크레딧
  ↓
새로운 생성 작업에 크레딧 사용
  ↓
부족 시 충전
  ↓
인쇄 주문
  ↓
B2B / Enterprise
```

### 크레딧

새로운 생성에만 사용합니다.

예:

- 포스터 생성

- 추가 제작물
- 상세페이지
- 리플렛
- 프로그램북

- 기존 결과 다운로드
- 단순 위치 / 크기 수정
- 텍스트 정보 수정 후 재렌더링

현재 사업계획용 가설:

> 1 Credit ≈ 250 KRW

실제 단가는 베타 데이터 이후 확정합니다.

### 인쇄

## 17. PoC 현황

### 확인 완료

```text

텍스트·사진·로고 재배치
```

## 21. 프로젝트 방향

ACTSET의 장기 성장 방향은 다음과 같습니다.

```text
공연 포스터 생성
    ↓
공연 홍보물 제작 플랫폼
    ↓
공연 출시 준비 플랫폼
```

고객 확장 방향:

```text
예술대학생 / 독립예술인
    ↓
공연단체
    ↓
공연기획사
    ↓
공연장 / 문화재단 / 기관
```
